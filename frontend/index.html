    Cargar catálogo desde CSV

    Sirve para el archivo que te envía un mayorista o para un Excel exportado como CSV. Obligatorias: sku, titulo, costo. Opcionales: categoria, costo_envio, dias_envio, almacen, stock, pedidos, rating, imagen, url, etiquetas. Acepta separador , o ; y decimales con coma o punto. Descargar plantilla.

    Reglas de precio

    Precio sugerido = (costo + envío) × multiplicador + monto fijo, redondeado a .99. La comisión se descuenta para calcular ganancia y margen.
